Track A: Top 5 Curated (Deterministic Heuristic Pipeline)
Show-Harness: Foundation VLM Agents for Zero‑Shot Robot Control
Research & Papers • Source: ArXiv • ▲ 66 upvotes • ✓ 200 OK
Show-Harness adapts pretrained vision‑language models (VLMs) into embodied agents that map visual observations and language commands directly to robot actions. By fine‑tuning the VLM on a curated harness of demonstration trajectories and introducing a proprioceptive alignment loss, the framework achieves zero‑shot manipulation and navigation on both simulated and real‑world platforms. Experiments on Meta‑World show a 23% gain over prior VLM‑to‑robot pipelines while using a 1.3B‑parameter VLM backbone.
Programmable World Model: Differentiable Memory for Controllable Video Generation
Research & Papers • Source: ArXiv • ▲ 53 upvotes • ✓ 200 OK
This work augments video diffusion models with a differentiable memory module that maintains a consistent latent world state across frames, allowing users to enforce logical constraints such as object permanence or physics via a programmable interface. Trained on 10M video clips, the model attains a 4.2 FVD improvement over baselines and supports real‑time scene editing at 30 fps on a single A100 GPU. The memory module adds <15% overhead and can be steered with natural‑language rules.
AgentGrad: Intervention‑Guided Prompt Optimization for Multi‑Agent LLMs
Research & Papers • Source: ArXiv • ▲ 43 upvotes • ✓ 200 OK
AgentGrad treats prompt tokens as continuous variables and learns a surrogate critic that estimates joint task performance, enabling gradient‑based optimization of each agent’s prompts in a multi‑agent LLM system. Applied to a three‑agent debate setup on MMLU, it lifts average accuracy from 68.1% to 74.5% without increasing model size and adds less than 5% computational overhead. The method works with black‑box APIs by approximating gradients via finite‑difference interventions.
DeepSeek Unveils V4.1‑Flash: 552B‑Parameter MoE Model with 1M‑Token Context
Industry & Models • Source: Techmeme • ⚠ Protected (401)
DeepSeek releases V4.1‑Flash, a mixture‑of‑experts model built on a novel Causal Encoder‑Decoder architecture, featuring 552 billion parameters and a 1‑million‑token context window. Trained on 15 TB of multilingual text and code, it scores 78.9% MMLU and 62.3% HumanEval, outperforming prior dense 1T‑parameter models while consuming 40% fewer FLOPs per token. The model is released under a permissive license and includes 4‑bit quantized versions that fit in 2 TB of RAM for inference.
Positron’s Asimov AI Processor: Memory‑First Architecture with 2.3TB On‑Die HBM
Infrastructure & Tools • Source: Techmeme • ⚠ Protected (401)
Positron announces the Asimov chip, a memory‑first AI processor that integrates up to 2.3 TB of HBM3e memory directly on the die, targeting transformer workloads with >1 PFLOPS sparse matrix‑multiply performance. The 3D‑stacked compute‑in‑memory design cuts data movement by ~70% versus conventional GPUs, enabling training of 10‑trillion‑parameter models at 150 TFLOPS/W. Backed by an $875 M Series A at a $5 B valuation, tape‑out is planned for Q1 2027.
